# 미션 2 기록

- 사용한 AI 이름 / 대화 공유 링크 또는 캡처 파일명: Claude Code /클로드 대화.png
- 좁혀서 적은 한 문장: 제목에 띄어쓰기가 있는 영화(센과 치히로의 행방불명, 어벤져스: 엔드게임, 토이 스토리)만 누르기와 끌어 놓기 둘 다 랭크 칸으로 옮겨지지 않고, 띄어쓰기 없는 영화는 옮겨진다
- 좁히려고 해 본 것과 결과: 영화 8개를 하나씩 옮겨 봄 → 3개만 안 옮겨짐. 안 되는 3개는 모두 제목에 띄어쓰기가 있고 되는 5개는 없음. 띄어쓰기 있는 제목을 추가해 같은 결과가 나오는지는 확인 
- AI가 말한 원인과, 그 설명을 직접 확인한 결과: 카드 이름표에 따옴표가 없어 띄어쓰기 앞에서 끊겨 옮길 영화를 찾지 못함. 직접 확인한 결과 띄어쓰기 된 영화도 정상적으로 작동하는 것 확인
