# 영화 티어리스트 웹페이지 기획서

## 1. 누가 쓰나
- 친구·지인과 공유하는 용도로 쓴다.
- 만드는 사람은 본인이다.

## 2. 무엇을 하려고
- 내가 본 영화에 대한 취향을 기록한다.

## 3. 화면과 동작
- 영화 카드를 드래그 앤 드롭으로 티어 행에 배치한다.
- 티어는 S / A / B / C / D 다섯 단계이며 이름과 색은 고정이다.
- 처음 열면 기본 영화 10편이 "아직 분류하지 않은 영화" 영역에 있다.
- 영화는 제목을 입력하고 포스터 이미지 파일을 골라 직접 추가할 수 있다.
- 만든 티어리스트는 브라우저에 자동 저장된다.
- 하나의 HTML 파일(HTML·CSS·JavaScript 포함)로 외부 파일이나 서버 없이 브라우저에서 바로 열린다.
- 화면 문구는 한국어다.

## 4. 필요한 자료
- 기본 영화 10편의 제목과 포스터: 기생충, 인터스텔라, 다크 나이트, 올드보이, 겨울왕국, 라라랜드, 인셉션, 타이타닉, 매트릭스, 어벤져스: 엔드게임.
  - 포스터는 위키백과 영화 문서의 이미지를 HTML 파일 안에 포함했다.
- 추가하는 영화의 제목과 포스터 이미지: 직접 입력한다.
- 외부 영화 API는 쓰지 않는다.

## 5. 완성 기준
- [x] 영화를 추가할 수 있다.
- [x] 카드를 드래그해서 이동할 수 있다.
- [x] 새로고침 후에도 배치가 유지된다.

## 아직 정하지 않은 것
- 친구·지인에게 공유하는 방법(링크, 이미지 내보내기 등). 브라우저 자동 저장만으로는 다른 사람에게 보여줄 수 없다.
- 모바일 터치 드래그 지원 여부.
- 영화 삭제·수정 기능. 현재는 없다.
- 페이지 디자인. 현재는 어두운 배경에 등급별 색을 임의로 정한 상태다.
- 기본 영화 목록을 이 10편으로 확정할지 여부.
- 배포 방식(파일로 열기, 웹 호스팅 등).
