# 미션 3 기록

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI: 저장 기능이 없다 | 영화를 옮기고 파일을 다시 열었더니 전부 미분류로 돌아갔다 | 반영 | 기획서 완성 기준 “다시 열어도 영화와 등급이 남습니다”에 맞지 않는다 |
| AI: ‘처음으로’가 직접 추가한 영화를 지우지 않는다 | 영화를 추가한 뒤 ‘처음으로’를 눌렀더니 처음 영화 8개만 남고 추가한 영화는 사라졌다 | 보류 | 직접 해 보니 AI가 말한 문제가 없고, 기획서의 “처음 영화 8개가 모두 미분류로 돌아갑니다”와 이미 맞다 |
| AI: 빈 제목을 막지 않는다 | 제목을 비우고 ‘추가’를 누르니 글자 없는 빈 카드가 생겼다 | 반영 | 빈 카드는 쓸 수 없고, 기획서의 “제목을 입력하면 새 영화 카드가 생깁니다”는 제목이 있을 때를 전제로 한 약속이다 |
| 동료: 휴대폰으로 열어 보니 불편했다 | 직접 확인해 보지 못했다 | 되묻기 | 휴대폰에서 어떤 동작(글자 크기, 버튼 누르기, 카드 옮기기 등)이 불편했나요? |
| 동료: 카드 옮기는 게 처음엔 헷갈렸다 | 안내 문구가 있지만 무엇이 헷갈렸는지 알 수 없다 | 되묻기 | 선택 후 등급 누르기와 끌어 놓기 중 어느 쪽이, 어느 단계에서 헷갈렸나요? |
| 동료: 안 정한 영화가 맨 아래라 S칸까지 끌어 올리기 불편하다 | 화면이 길어서 끌어 올릴 때 스크롤이 필요한 건 맞다. 카드를 누르고 등급 글자를 누르면 스크롤 없이 옮길 수 있다 | 보류 | 기획서가 “위에 S·A·B·C 칸, 아래에 아직 안 정한 영화”로 배치를 정했고, 끌기가 불편한 사람은 클릭으로 옮길 수 있다 |
| 동료: 카드 색이 칙칙하다 | 카드가 회색 계열이긴 하지만 글자 읽기에는 문제가 없다 | 보류 | 취향의 문제이고, 기획서의 목적이나 완성 기준과 관련이 없어 꼭 바꿀 이유가 없다 |
| 동료: 영화 포스터 사진이 있으면 좋겠다 | 지금은 제목 글자만 있는 카드다 | 보류 | 기획서가 “외부 파일이나 로그인 없이 HTML 한 장”으로 열리는 것을 약속했고, 포스터는 이 약속과 부딪힌다 |
| 동료: C칸은 없어도 될 것 같다 | C칸이 비어 있어도 사용에는 문제가 없다 | 보류 | 기획서가 S·A·B·C 네 칸으로 나누는 것을 목적으로 정했고, C칸이 불필요하다는 근거가 취향뿐이다 |

- 아무도 말하지 않았는데 내가 찾은 것: 브라우저 화면 폭을 좁히면 오른쪽 내용이 잘려서 보이지 않는다. 기획서 완성 기준 “화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다”에 맞지 않으므로 반영할 예정이다.
