# 등각 타로 한 판

## 대상 사용자

- 타로를 잘 모르지만 오늘의 운세를 가볍게 보고 싶은 사람. 노트북과 휴대폰으로 잠깐 열어 22장의 카드 더미에서 마음이 끌리는 3장을 직접 골라 봅니다.

## 사용 목적

- 부채꼴로 펼쳐진 22장의 카드 더미에서 3장을 직접 골라 과거·현재·미래 자리에 순서대로 놓아 보며, 카드마다 짧은 해석을 읽고 오늘의 운세를 재미로 봅니다.

## 화면 구성과 동작

- 맨 위에 제목 ‘✦ 등각 타로 한 판’과 안내 문구, 우측에 ‘소리 켜기/끄기’ 버튼과 ‘다시 뽑기’ 버튼이 있습니다.
- 보라색·짙은 남색 벨벳 천이 덮인 등각(30도 기울기) 테이블이 화면 가운데에 있습니다. 테이블 가장자리에 흔들리는 촛불, 빛나는 수정구, 4개의 금빛 룬 문양이 있습니다.
- 테이블 위쪽에는 각각 ‘과거 · 현재 · 미래’ 이름표가 붙은 빈 카드 자리(`?` 표시된 점선 칸) 3칸이 가로로 놓여 있습니다.
- 테이블 아래쪽에는 메이저 아르카나 22장이 무작위로 섞인 채 뒷면(금색 테두리와 기하학 무늬)이 보이도록 11장씩 2줄 부채꼴 모양으로 펼쳐져 있습니다. (직접 고르는 재미를 높이기 위해 부채꼴 카드 더미 추가)
- 카드 더미나 놓인 카드에 마우스를 올리면(또는 키보드 포커스를 주면) 카드가 위로 살짝 떠오르고 금빛이 번집니다.
- 부채꼴 카드 더미에서 원하는 카드를 누르면 해당 카드는 더미에서 사라지고, 위쪽 빈 자리에 ‘과거 → 현재 → 미래’ 순서대로 놓이면서 3D로 뒤집혀 앞면의 로마 숫자, 단순한 벡터 그림, 한글·영문 카드 이름이 보입니다.
- 3장을 모두 고르면 남은 카드 더미는 반투명해지며 비활성화됩니다.
- 테이블 아래 안내 배너가 현재 골라야 할 위치(‘과거’, ‘현재’, ‘미래’)와 완료 상태를 차례대로 알려줍니다.
- 화면 아래 설명 상자(‘오늘의 타로 해석’)에는 고른 카드 수(`고른 카드: n / 3`)와 함께 과거·현재·미래 3칸이 표시되며, 카드를 고른 자리마다 ‘로마 숫자. 한글 이름 (영문 이름) · 위치(과거/현재/미래)’와 그 위치에 맞는 해석이 나옵니다.
- ‘다시 뽑기’ 버튼을 누르면 과거·현재·미래 3칸이 다시 빈 자리(`?`)로 초기화되고, 설명 상자가 비워지며, 22장의 카드 더미가 새로 섞여 다시 펼쳐집니다.
- 카드를 고를 때와 다시 뽑을 때 효과음이 나고, 잔잔한 화음과 종소리 배경음이 흐릅니다. ‘소리 켜기/끄기’ 버튼으로 끄고 켭니다.

## 필요한 자료

- 메이저 아르카나 22장: 로마 숫자(0~XXI), 이름(한글·영문), 단순한 벡터 그림, 위치별(과거/현재/미래) 해석 문장
- 카드 뒷면 기하학 무늬, 등각 테이블, 촛불·수정구·룬 그림 (모두 SVG와 CSS로 직접 그립니다)
- 카드 고르기·다시 뽑기 효과음과 배경음 (외부 파일 없이 브라우저의 Web Audio API로 만듭니다)

## 완료 기준

- 부채꼴로 펼쳐진 22장의 카드 더미에서 3장을 고르면 과거·현재·미래 자리에 순서대로 놓이며 3D로 뒤집히고, 서로 다른 카드 3장이 나옵니다.
- 이미 뽑은 카드는 더미에서 사라져 다시 누를 수 없고, 3장을 모두 뽑으면 남은 카드는 더 이상 선택되지 않습니다.
- 고른 카드마다 과거·현재·미래 중 자기 위치에 맞는 해석이 아래 설명 상자의 해당 칸에 나옵니다.
- ‘다시 뽑기’를 누르면 과거·현재·미래 3칸이 빈 자리(`?`)로 초기화되고 설명 상자가 비워지며, 22장이 새로 섞여 부채꼴로 다시 펼쳐집니다.
- 카드에 마우스를 올리거나 키보드 초점을 이동하면 카드가 위로 떠오르고 금빛이 납니다.
- 소리 버튼을 끄면 효과음과 배경음이 모두 멈춥니다. 처음 열었을 때 소리는 사용자가 ‘소리 켜기’를 누르기 전까지 나지 않습니다.
- 휴대폰 화면(640px 이하)에서도 테이블과 카드 자리 3칸, 부채꼴 카드 더미, 설명 상자가 가로 스크롤 없이 보입니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.
- 뽑은 결과는 저장하지 않습니다.

## 필수 기능

- 과거·현재·미래 빈 카드 자리 3칸과 22장 부채꼴 카드 더미 뒷면 표시
- 22장 무작위 섞기(Fisher-Yates 셔플) 및 선택한 카드를 순서대로 놓고 3D로 뒤집기
- 과거·현재·미래 위치별 해석 표시
- 다시 뽑기(자리 초기화 및 카드 더미 다시 섞어 펼치기)
- 등각 테이블 화면과 호버·키보드 포커스 효과
- 효과음·배경음과 소리 켜기/끄기

## 추가 기능

- 카드 역방향(거꾸로 나옴)과 역방향 해석
- 뽑은 결과를 브라우저에 저장하고 날짜별로 보기
- 78장 전체(마이너 아르카나 포함)
- 질문을 직접 입력해 보는 모드

## 한계 및 비목표

1. 메이저 아르카나 22장만 나오고, 카드 그림은 단순한 벡터(SVG) 그림입니다.
2. 등각 테이블은 CSS `rotateX(30deg)`로 기울인 무대 형태이며, 실제 3D 물리 엔진을 쓰지 않습니다.
3. 해석은 재미를 위한 짧은 일반 문장이며, 실제 점술이나 전문 조언이 아닙니다.
4. 결과가 저장되지 않아 창을 닫거나 새로고침하면 사라집니다.

## 검증 방법

- 20번 이상 다시 뽑아 한 판 안에서 같은 카드가 두 번 나온 적이 없는지, 3장을 고른 뒤 추가 선택이 막히는지 확인하고, 화면의 카드 이름·위치별 해석이 코드 내 `MAJOR_ARCANA` 자료에 적은 문장과 일치하는지 대조합니다.
