# 제작·검증 기록: 등각 타로 한 판

## 두 AI 비교
- AI A (서비스·모델 이름): 클로드 코드(sonnet 5) → `타로_클로드.html`
- AI B (서비스·모델 이름): 제미나이(argon) → `타로_제미나이.html`
- 동일한 기획서와 함께 전달한 요청: 타로를 할 수 있는 웹페이지를 만들어 달라고 요청


| 테스트 내용 | AI A (클로드) | AI B (제미나이) |
| --- | --- | --- |
| 등각 테이블 | 테이블을 `rotateX(60deg) rotateZ(45deg)`로 눕힌 마름모. 카드·촛불·수정구는 테이블 위에 평평하게 눕지 않고 정면으로 세워져 있음 | 사각형 판을 `rotateX(30deg)`로 기울인 것. 소품은 `translateZ`로 띄웠고 카드는 테이블 안에 배치. 진짜 등각 투영보다는 "기울어진 판"에 가까움 |
| 소품 | 촛불 2·수정구·룬 2개(텍스트 룬 문자) | 촛불·수정구·룬 4개를 SVG로 그림, 깜빡임/빛남 애니메이션 |
| 카드 앞면 그림 | 22장 모두 짧은 SVG 한 덩어리, 단순함 | 22장 각각 윤곽선과 금색을 쓴 SVG, 로마 숫자 표시 |
| 설명 상자 | 뒤집은 카드의 해석만 쌓아서 보여줌 (처음엔 안내 문구) | 항상 3칸(과거·현재·미래)을 보여주고 안 뒤집힌 칸은 흐리게 표시, "뒤집힌 카드 n/3" 표시 |
| 다시 뽑기 | 누르면 바로 새 카드로 교체(뒤집힌 채 돌아가는 동작은 없음) | 뒤집힌 카드를 먼저 되돌린 뒤 0.28초 뒤 새 카드로 교체. 되돌리는 애니메이션(0.72초) 도중에 앞면 그림이 바뀔 수 있음 |
| 소리 | 처음엔 꺼짐. 켜면 낮은 화음 3개 + 뒤집을 때 효과음. 끄면 일시 정지 | 처음엔 꺼짐. 켜면 화음 4개 + 종소리가 주기적으로 울림, 카드마다 다른 음, 다시 뽑기 소리도 있음 |
| 휴대폰 화면 | 카드 폭을 `clamp`로 줄임. 마름모 테이블이 화면보다 넓어져 넘치는 부분은 `overflow-x:hidden`으로 가려짐 | 640px 이하에서 테이블·카드·설명 상자를 세로 한 줄로 바꿈 |
| 접근성·터치 | 키보드로 카드를 못 뒤집음. 호버 효과가 터치 기기에서도 남을 수 있음 | 카드에 키보드(Enter·Space) 지원, `aria-live`, 호버는 마우스가 있는 기기에서만 적용 |
| 안내 문구 | 설명 상자 안내 한 줄 | 안내 배너, 하단 안내문(재미용·저장 안 됨) 포함 |

- 선택한 결과물과 근거: **`타로_제미나이.html`
  - 근거 1: 기획서 완료 기준에서 "소리를 켜기 전까지 소리 없음", "휴대폰에서 가로 스크롤 없이 보임", "이미 뒤집힌 카드를 다시 눌러도 안 바뀜"을 둘 다 만족하지만, 제미나이 쪽이 휴대폰 레이아웃을 따로 만들었고 키보드·터치 대응이 더 갖춰져 있습니다.
  - 근거 2: 설명 상자가 3칸으로 고정되어 어느 위치의 해석인지 한눈에 보이고, 기획서의 "한계" 항목(재미용, 저장 안 됨)이 화면에 적혀 있습니다.
  - 아쉬운 점: 등각(30도)은 클로드의 마름모 테이블이 더 가깝습니다. 실제 브라우저로 두 파일을 열어 본 뒤 최종 확정하세요.

## 테스트 기록
| 번호 | 테스트 내용 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | 카드 3장을 모두 누르고, 이미 뒤집힌 카드를 다시 누르기 / 다시 뽑기 | 3장이 각각 뒤집히고, 다시 눌러도 카드가 바뀌지 않으며, 다시 뽑기 후 모두 뒷면 + 설명 비워짐 | 코드상 두 파일 모두 뒤집힌 카드는 클릭해도 카드를 바꾸지 않음(클로드는 무시, 제미나이는 해당 해석만 다시 강조). 다시 뽑기는 클로드는 즉시 새 카드로 교체, 제미나이는 뒷면으로 돌린 뒤 교체. **브라우저 실제 확인은 필요** |
| 2 (좁은 화면·빈칸 입력·인쇄 등 조건을 바꿔 테스트) | 브라우저 폭을 360px로 줄여 테이블·카드 3장·설명 상자가 가로 스크롤 없이 보이는지 확인 | 가로 스크롤 없이 모두 보임 | 코드상 두 파일 모두 `overflow-x:hidden`이라 스크롤은 안 생김. 클로드는 마름모 테이블이 화면 폭을 넘어 잘릴 수 있고, 제미나이는 640px 이하 전용 레이아웃이 있음. **실제 화면 확인 필요** |
| 3 | 소리 버튼을 누르기 전 / 누른 후 / 다시 끄기 | 처음엔 소리 없음, 켜면 배경음과 효과음, 끄면 모두 멈춤 | 코드상 두 파일 모두 처음 상태는 꺼짐이고 켠 뒤에만 오디오가 만들어짐. 끄기는 클로드는 `ac.suspend()`, 제미나이는 화음을 `stop()`하고 타이머를 해제. **귀로 확인 필요** |

## 수정 기록

### 수정 기록 1
- 발견한 문제: (제미나이) 다양한 타로 카드 중에서 3장을 뽑는 형식이 아닌 이미 뽑혀져 있는 3 장의 카드를 뒤집는 것 밖에 안되는 문제를 발견
- AI에게 전달한 요청: 타로의 모든 카드가 있는 상태에서 3장을 뽑는 형식으로 수정해달라고 요청
- 수정 후 테스트 결과: 총 22장 중 3장의 카드를 뽑는 형식으로 수정된 것을 직접 실행함으로서 확인 할 수 있었음
- 수정 이유: 자신이 뽑는다는 재미가 있는 타로에서 이미 뽑혀져있는걸 뒤집는 것은 재미를 감소시키기 때문에

### 수정 기록 2
- 발견한 문제: 카드가 도형으로 이루어져 있어 실감이 나지 않음
- AI에게 전달한 요청:실제 사용되는 타로 이미지를 주고 타로카드를 이 이미지로 채워달라고 요청
- 수정 후 테스트 결과: 카드가 이미지로 변경된 것 확인
- 수정 이유: 타로를 진행함에 있어서 좀 더 현실적인 부분을 가미해 재미를 증가시키기 위해

### 수정 기록 3
- 발견한 문제: 마우스로만 타로 카들르 뽑을 수 있는 문제
- AI에게 전달한 요청: 방향키, enter, r을 이용해 카드를 선택하고 다시뽑기를 할 수 있도록 요청
- 수정 후 테스트 결과: 키보드 키를 이용해 뽑을 수 있는 것 확인
- 수정 이유: 마우스 뿐만 아니라 키보드를 이용해서 타로를 할 수 있는 다양한 선택지가 있는 것이 더 편의성을 제공할 수 있다고 생각했기 때문에

## 사용자 테스트
- 테스트 참여자와 요청한 작업:여러번 타로카드를 뒤집으면서 테스트
- 사용자의 행동과 질문: 역방향에 대한 의미가 따로 있는지 문의
- 받은 피드백:타로에 역방향에 대한 의미가 있으니 이를 반영하면 더 좋을 것
- 반영 내용과 결과: 다양한 해석에 역방향에 대한 의미도 추가
