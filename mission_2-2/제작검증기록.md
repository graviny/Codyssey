# 제작·검증 기록: 등각 타로 한 판

## 두 AI 비교
- AI A (서비스·모델 이름): 클로드 코드(sonnet 5) → `타로_클로드.html`
- AI B (서비스·모델 이름): 제미나이(argon) → `타로_제미나이.html`
- 동일한 기획서와 함께 전달한 요청: 타로를 할 수 있는 웹페이지를 만들어 달라고 요청

> 아래 비교는 두 HTML의 소스 코드를 읽고, 뽑기 로직은 Node에서 실제 스크립트를 1,000번 돌려 얻은 결과입니다. 호버·뒤집기 애니메이션·소리·실제 휴대폰 화면은 브라우저에서 직접 보고 확인한 것이 아니므로 "코드상"이라고 표시했습니다.

| 테스트 내용 | AI A (클로드) | AI B (제미나이) |
| --- | --- | --- |
| 22장 중 겹치지 않게 3장 뽑기 (1,000회 실행) | 중복 0회, 22장 모두 등장 | 중복 0회, 22장 모두 등장 |
| 카드 자료 | 22장 × 위치별 해석 3개, 빠진 것 없음 | 22장 × 위치별 해석 3개, 빠진 것 없음 |
| 등각 테이블 | 테이블을 `rotateX(60deg) rotateZ(45deg)`로 눕힌 마름모. 카드·촛불·수정구는 테이블 위에 평평하게 눕지 않고 정면으로 세워져 있음 | 사각형 판을 `rotateX(30deg)`로 기울인 것. 소품은 `translateZ`로 띄웠고 카드는 테이블 안에 배치. 진짜 등각 투영보다는 "기울어진 판"에 가까움 |
| 소품 | 촛불 2·수정구·룬 2개(텍스트 룬 문자) | 촛불·수정구·룬 4개를 SVG로 그림, 깜빡임/빛남 애니메이션 |
| 카드 앞면 그림 | 22장 모두 짧은 SVG 한 덩어리, 단순함 | 22장 각각 윤곽선과 금색을 쓴 SVG, 로마 숫자 표시 |
| 설명 상자 | 뒤집은 카드의 해석만 쌓아서 보여줌 (처음엔 안내 문구) | 항상 3칸(과거·현재·미래)을 보여주고 안 뒤집힌 칸은 흐리게 표시, "뒤집힌 카드 n/3" 표시 |
| 다시 뽑기 | 누르면 바로 새 카드로 교체(뒤집힌 채 돌아가는 동작은 없음) | 뒤집힌 카드를 먼저 되돌린 뒤 0.28초 뒤 새 카드로 교체. 되돌리는 애니메이션(0.72초) 도중에 앞면 그림이 바뀔 수 있음 |
| 소리 | 처음엔 꺼짐. 켜면 낮은 화음 3개 + 뒤집을 때 효과음. 끄면 일시 정지 | 처음엔 꺼짐. 켜면 화음 4개 + 종소리가 주기적으로 울림, 카드마다 다른 음, 다시 뽑기 소리도 있음 |
| 휴대폰 화면 | 카드 폭을 `clamp`로 줄임. 마름모 테이블이 화면보다 넓어져 넘치는 부분은 `overflow-x:hidden`으로 가려짐 | 640px 이하에서 테이블·카드·설명 상자를 세로 한 줄로 바꿈 |
| 접근성·터치 | 키보드로 카드를 못 뒤집음. 호버 효과가 터치 기기에서도 남을 수 있음 | 카드에 키보드(Enter·Space) 지원, `aria-live`, 호버는 마우스가 있는 기기에서만 적용 |
| 안내 문구 | 설명 상자 안내 한 줄 | 안내 배너, 하단 안내문(재미용·저장 안 됨) 포함 |

- 선택한 결과물과 근거: **`타로_제미나이.html` (잠정 선택)**
  - 근거 1: 기획서 완료 기준에서 "소리를 켜기 전까지 소리 없음", "휴대폰에서 가로 스크롤 없이 보임", "이미 뒤집힌 카드를 다시 눌러도 안 바뀜"을 둘 다 만족하지만, 제미나이 쪽이 휴대폰 레이아웃을 따로 만들었고 키보드·터치 대응이 더 갖춰져 있습니다.
  - 근거 2: 설명 상자가 3칸으로 고정되어 어느 위치의 해석인지 한눈에 보이고, 기획서의 "한계" 항목(재미용, 저장 안 됨)이 화면에 적혀 있습니다.
  - 아쉬운 점: 등각(30도)은 클로드의 마름모 테이블이 더 가깝습니다. 실제 브라우저로 두 파일을 열어 본 뒤 최종 확정하세요.

## 테스트 기록
| 번호 | 테스트 내용 | 예상 결과 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | 다시 뽑기를 1,000번 실행해 한 판에 같은 카드가 나오는지 확인 (두 파일의 실제 스크립트를 Node로 실행) | 한 판에 같은 카드가 두 번 나오지 않고, 22장이 모두 나올 수 있음 | 클로드·제미나이 모두 중복 0회, 22장 모두 등장. 22장 × 과거·현재·미래 해석에 빠진 문장 없음 |
| 2 | 카드 3장을 모두 누르고, 이미 뒤집힌 카드를 다시 누르기 / 다시 뽑기 | 3장이 각각 뒤집히고, 다시 눌러도 카드가 바뀌지 않으며, 다시 뽑기 후 모두 뒷면 + 설명 비워짐 | 코드상 두 파일 모두 뒤집힌 카드는 클릭해도 카드를 바꾸지 않음(클로드는 무시, 제미나이는 해당 해석만 다시 강조). 다시 뽑기는 클로드는 즉시 새 카드로 교체, 제미나이는 뒷면으로 돌린 뒤 교체. **브라우저 실제 확인은 필요** |
| 3 (좁은 화면·빈칸 입력·인쇄 등 조건을 바꿔 테스트) | 브라우저 폭을 360px로 줄여 테이블·카드 3장·설명 상자가 가로 스크롤 없이 보이는지 확인 | 가로 스크롤 없이 모두 보임 | 코드상 두 파일 모두 `overflow-x:hidden`이라 스크롤은 안 생김. 클로드는 마름모 테이블이 화면 폭을 넘어 잘릴 수 있고, 제미나이는 640px 이하 전용 레이아웃이 있음. **실제 화면 확인 필요** |
| 4 | 소리 버튼을 누르기 전 / 누른 후 / 다시 끄기 | 처음엔 소리 없음, 켜면 배경음과 효과음, 끄면 모두 멈춤 | 코드상 두 파일 모두 처음 상태는 꺼짐이고 켠 뒤에만 오디오가 만들어짐. 끄기는 클로드는 `ac.suspend()`, 제미나이는 화음을 `stop()`하고 타이머를 해제. **귀로 확인 필요** |
