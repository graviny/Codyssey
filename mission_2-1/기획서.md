# 등각 타로 한 판

## 대상 사용자

- 타로를 잘 모르지만 오늘의 운세를 가볍게 보고 싶은 사람. 노트북과 휴대폰으로 잠깐 열어 3장을 뽑아 봅니다.

## 사용 목적

- 카드 3장을 뽑아 과거·현재·미래 순서로 뒤집어 보며, 카드마다 짧은 해석을 읽고 오늘의 운세를 재미로 봅니다.

## 화면 구성과 동작

- 보라색·짙은 남색 벨벳 천이 덮인 등각(30도) 테이블이 화면 가운데에 있습니다. 테이블 가장자리에 촛불, 수정구, 빛나는 룬 문양이 있습니다.
- 테이블 가운데에 뒷면이 보이는 카드 3장이 가로로 놓여 있고, 각각 ‘과거 · 현재 · 미래’ 이름표가 붙어 있습니다. 카드 뒷면은 금색 테두리의 무늬입니다.
- 카드에 마우스를 올리면 카드가 위로 살짝 떠오르고 금빛이 번집니다. (휴대폰은 한 번 누르면 뒤집힙니다)
- 카드를 누르면 3D로 뒤집히면서 앞면의 단순한 그림과 카드 이름이 보입니다. 카드는 메이저 아르카나 22장 중 겹치지 않게 무작위로 정해집니다.
- 카드가 뒤집히면 화면 아래 설명 상자에 ‘카드 이름 · 위치(과거/현재/미래)’와 그 위치에 맞는 해석이 나옵니다.
- ‘다시 뽑기’ 버튼을 누르면 카드가 모두 뒷면으로 돌아가고 새로 3장이 정해집니다.
- 카드를 뒤집을 때 효과음이 나고, 배경음이 잔잔하게 흐릅니다. ‘소리’ 버튼으로 끄고 켭니다.

## 필요한 자료

- 메이저 아르카나 22장: 이름(한글·영문), 단순한 벡터 그림, 위치별(과거/현재/미래) 해석 문장
- 카드 뒷면 무늬, 등각 테이블, 촛불·수정구·룬 그림 (모두 SVG와 CSS로 직접 그립니다)
- 효과음과 배경음 (파일 없이 브라우저의 Web Audio로 만듭니다)

## 완료 기준

(페이지의 완료 여부를 판단할 조건을 작성합니다)

- 카드 3장을 모두 누르면 각각 뒤집히고, 서로 다른 카드 3장이 나옵니다.
- 이미 뒤집힌 카드를 다시 눌러도 바뀌지 않습니다.
- 뒤집힌 카드마다 과거·현재·미래 중 자기 위치에 맞는 해석이 설명 상자에 나옵니다.
- ‘다시 뽑기’를 누르면 3장이 모두 뒷면으로 돌아가고 설명 상자가 비워지며, 새 카드로 다시 뽑힙니다.
- 카드에 마우스를 올리면 위로 떠오르고 금빛이 납니다.
- 소리 버튼을 끄면 효과음과 배경음이 모두 멈춥니다. 처음 열었을 때 소리는 사용자가 누르기 전까지 나지 않습니다.
- 휴대폰 화면에서도 테이블과 카드 3장, 설명 상자가 가로 스크롤 없이 보입니다.
- 다른 파일이나 로그인 없이 HTML 파일 하나로 열립니다.
- 뽑은 결과는 저장하지 않습니다.

## 필수 기능

- 카드 3장 뒷면 표시, 카드를 누르면 뒤집기
- 22장 중 겹치지 않게 3장 무작위 뽑기
- 과거·현재·미래 위치별 해석 표시
- 다시 뽑기
- 등각 테이블 화면과 호버 효과
- 효과음·배경음과 소리 켜기/끄기

## 추가 기능

- 카드 역방향(거꾸로 나옴)과 역방향 해석
- 뽑은 결과를 브라우저에 저장하고 날짜별로 보기
- 78장 전체(마이너 아르카나 포함)
- 질문을 직접 입력해 보는 모드

## 한계 및 비목표

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)

1. 메이저 아르카나 22장만 나오고, 카드 그림은 단순한 벡터 그림입니다.
2. 해석은 재미를 위한 짧은 일반 문장이며, 실제 점술이나 조언이 아닙니다.
3. 결과가 저장되지 않아 창을 닫으면 사라집니다.

(기획 단계에서 초안을 작성하고, 최종 HTML에 맞게 수정합니다)
